# Base trace assessment

All nine fresh trials independently achieved the same typed record change and preserved unrelated fields/records. Next used 126,085.67 tokens per success versus 89,044.67 for original guidance and 93,971.67 for concise guidance. This is a measured regression in this small workload.

Next used 11 command executions in every trial; the original arm used 5, 5, 9 and concise used 8, 9, 9. Each Next trace contains four help/discovery executions, versus 1, 1, 3 for original and three for each concise trial. Two Next trials began with discovery. Next selected record-list plus saved-artifact inspection before and after mutation; both baselines selected exact record-get, with fewer preliminary reads in two original trials. The concise Base guide explicitly describes exact-ID reads and the single-record update path; Next's entry delegates domain details to help/on-demand documentation. No Next trial read that inherited domain skill in the retained trace.

Recovery and checking contributed real work: one Next list invocation exited 2 before its corrected invocation; two Next batch updates exited 22 and were followed by readback. One Next and two concise script attempts exited 127 before successful script execution. The remaining Next mutation used single-record upsert and exited 0. Readback established the requested state without replaying a mutation. These checks are not automatically unnecessary: they provide outcome evidence after uncertainty.

API totals were equal for Next and original at 25, versus 33 for concise. The traces therefore do not support blaming extra API calls for Next's token regression. They support extra discovery/help and a different artifact/readback workflow as contributors to interaction length. Exact queries, payloads, script bodies, raw responses and per-command token attribution were not retained, so they cannot establish the token contribution of a specific output or the model's reason for choosing a command. Per-turn token totals also reflect context accumulation and model variation. No product/guidance tuning or performance rerun is prescribed from these three repetitions.
