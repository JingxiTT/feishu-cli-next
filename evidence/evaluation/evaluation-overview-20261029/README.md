# Consolidated evaluation overview

Read-only consolidation of five current GPT-6 Luna experiments against real Feishu, 25 retained older conditions and the original 43-task historical matrix. No new provider/model trial or tenant call was made.

`assessment.json` preserves per-experiment and per-workflow results, explicit qualifications, accounting inventory and source SHA-256 fingerprints. Current workload mixes are not pooled into an efficiency score. Historical conditions overlap or reuse prior rows and must not be summed as fresh usage.

`contact-attempts.json` retains the six original Contact outcome/usage rows unchanged and their sanitized public command traces; the private original enclosing metadata is omitted. Its source fingerprint binds it to the original local batch. The product hashes match the other current experiments.

The raw verdicts, native task interpretations, partial file verification, blocked IM setup, controller interruption records and historical limitations remain distinct. See the [full report](../../../evaluation/reports/evaluation-overview-20261029.md). No retained source record was edited and no held-out task manifest was read or used.
