All nine original Sheets attempts use the recorded +cells-get command and 8–11 shell executions. Eight verified concise-original attempts also record +cells-get with 7–13 executions; the ninth timed out at 180.63 seconds after 5 executions and 1 API request without a provider usage summary. That timeout remains an unknown cost, not a zero or a skipped attempt.

Next verified all nine sizes/repetitions with 5–7 shell executions. Its new export leaf is represented only by the recognized Sheets prefix in the pinned reference-based trace vocabulary, so the exact leaf cannot be recovered from this sanitized trace alone. All three 10,000-row Next attempts make 17 total backend requests each, compared with 3 each for the original and 3/3/7 for the concise original. Fewer tool steps and lower provider tokens coexist with more backend requests at that size.

Command/source arguments, output bodies and full artifacts are intentionally discarded after independent verification. These records cannot assign a per-command token price or establish that every observed difference comes from the output format. The exact typed local artifacts, signed complete native read coverage and unchanged remote source were checked independently for every verified outcome. All retained costs and the timeout remain in the same frozen balanced condition.
